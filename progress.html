Integrated Catchment Characterisation for Groundwater Vulnerability

Automated watershed delineation, morphometric analysis, and hydrogeological risk profiling | R & QGIS / GRASS Integration

Project Overview & Objectives

This project establishes a fully reproducible, automated geospatial workflow using R and QGIS/GRASS GIS (`qgisprocess`) to delineate watershed boundaries, extract stream networks, and execute catchment morphometric analysis across large Digital Elevation Model (DEM) datasets in Cheshire and Greater Manchester.

By integrating topographic indices with geological and aquifer datasets, the project aims to evaluate sub-basin hydrological responses and evaluate spatial patterns in groundwater vulnerability and recharge dynamics.

Core Objectives:

  1. Automate seamless multi-tile DEM mosiacing, hydrological conditioning, and r.watershed flow accumulation across regional study areas.
  2. Quantitatively validate derived stream networks against Ordinance Survey reference data (OS Open Rivers) using precision and recall metrics.
  3. Derive key sub-basin morphometrics including slope, elevation, Topographic Wetness Index (TWI), Stream Power Index (SPI), and drainage density.
  4. Incorporate hydrogeological layers to construct an integrated groundwater vulnerability matrix across individual catchment sub-basins.

    Automation via qgisprocess Done

    Automated grass:r.watershed processing across multiple DEM tiles using qgisprocess. Identified that tile-by-tile processing fragmented basin IDs at tile boundaries; refined the workflow to mosaic DEM tiles into a single combined raster before running watershed analysis once, eliminating boundary artefacts and substantially improving precision/recall against the reference river network (59.8% precision, 71.8% recall on the combined 4-tile study area).
