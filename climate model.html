Zero-Dimensional Global Climate Energy Balance Model in R

Simulating transient global surface warming, radiative forcing, and biogeochemical feedback dynamics (2000–2100+) | University of Bristol

Summary

This project implements a zero-dimensional (0D) global energy balance model (EBM) in R to simulate Earth’s surface temperature trajectory from the year 2000 through 2100 and beyond. The model couples logarithmic CO2 radiative forcing, Stefan-Boltzmann blackbody cooling, and dynamic temperature-dependent feedbacks—including ice-albedo decay, water vapour lapse rate, greenhouse gases (CH4, N2O), biophysical/biogeochemical vegetation responses, and sea spray aerosol forcing.

Model Framework & Core Components

The model simulates Earth's surface temperature by calculating top-of-atmosphere radiative balance using the fundamental Stefan-Boltzmann radiation law combined with transient forcing and feedback parameters:

  • Radiative Forcing ($F$): Logarithmic CO2 forcing relationship $F = 5.35 \cdot \ln(C_{\text{total}} / 400) + \text{Ozone Forcing}$ consistent with IPCC AR6 formulations.
  • Stefan-Boltzmann Emission: Blackbody radiation emitted from Earth surface $E = \varepsilon \cdot \sigma \cdot T^4$, where $\varepsilon = 0.62$ and $\sigma = 5.67 \times 10^{-8} \text{ W m}^{-2} \text{K}^{-4}$.
  • Water Vapour & Lapse Rate Feedback ($\lambda_{\text{wvlr}}$): Positive feedback parameter (+1.3 W m-2 K-1) increasing atmospheric moisture retention under warming.
  • Cryospheric Surface Albedo Feedback ($\alpha$): Temperature-dependent albedo reduction $\alpha = \alpha_1 + (k + p) \cdot \Delta T$ accounting for retreating snow and ice cover.

Expanded Climate Feedbacks & Forcings

Sea Spray Aerosol (SSA)

Evaluated direct scattering and cloud condensation nuclei effects, applying a net negative feedback weighting ($\lambda_{\text{seaspray}} = -0.049 \text{ W m}^{-2} \text{K}^{-1}$).

Soil & Wetland GHGs

Modeled temperature-induced natural releases of CH4 and N2O from biological sinks, introducing positive feedback parameters (+0.02 and +0.01 W m-2 K-1).

Tropospheric Ozone Forcing

Incorporated a constant positive radiative forcing (+0.9 W m-2) representing ozone impacts on photosynthetic plant carbon sequestration.

Key Model Results & Decadal Warming

Simulating from 2000 to 2100 under cumulative feedbacks resulted in a net surface temperature rise of 4.81 °C (initial: 14.85 °C; final: 19.66 °C). Decadal warming rates accelerate through 2030 before slightly decelerating due to negative aerosol feedbacks and logarithmic forcing saturation.

R Implementation Code

Below is the primary R script used to solve the transient energy balance equations and plot warming trajectories:

# Climate Energy Balance Model in R
# Constants
solar <- 1370                   # Solar constant (W/m^2)
sigma <- 5.67e-8                # Stefan-Boltzmann constant
emiss <- 0.62                   # Earth emissivity
p <- -0.001                     # Albedo parameter 1
k <- -0.002                     # Albedo parameter 2

# Feedback Parameters (W/m^2/K)
lambda_wvlr     <- 1.3          # Water vapor & lapse rate
lambda_dust     <- -0.006       # Dust feedback
lambda_CH4      <- 0.02         # Methane feedback
lambda_N2O      <- 0.01         # Nitrous Oxide feedback
lambda_seaspray <- -0.049       # Sea spray aerosol feedback
lambda_total    <- lambda_wvlr + lambda_dust + lambda_CH4 + lambda_N2O + lambda_seaspray

b <- 10                         # Vegetation CO2 inc per K warming
N <- 101                        # Years to simulate (2000-2100)

# Arrays
year <- numeric(N); TK <- numeric(N); TC <- numeric(N)
C_anthro <- numeric(N); C_veg <- numeric(N); C_total <- numeric(N)
C_CH4 <- numeric(N); C_N2O <- numeric(N); F <- numeric(N); L <- numeric(N); albedo <- numeric(N)

# Initial conditions (Year 2000)
year[1] <- 2000; C_anthro[1] <- 400; C_veg[1] <- 0
C_CH4[1] <- 1.8; C_N2O[1] <- 0.33
C_total[1] <- C_anthro[1] + C_veg[1] + C_CH4[1] + C_N2O[1]
albedo[1] <- 0.3; L[1] <- 0; ozone_forcing <- 0.9

# Dynamic Simulation Loop
for (i in 1:N) {
  if (i > 1) {
    year[i] <- year[i-1] + 1
    C_anthro[i] <- 400 * (1.01^(year[i] - year[1]))
    C_veg[i]    <- b * (TC[i-1] - TC[1])
    C_CH4[i]    <- C_CH4[1] * (1 + lambda_CH4 * (TC[i-1] - TC[1]))
    C_N2O[i]    <- C_N2O[1] * (1 + lambda_N2O * (TC[i-1] - TC[1]))
    C_total[i]  <- C_anthro[i] + C_veg[i] + C_CH4[i] + C_N2O[i]
    albedo[i]   <- albedo[1] + k * (TC[i-1] - TC[1]) + p * (TC[i-1] - TC[1])
    L[i]        <- lambda_total * (TC[i-1] - TC[1])
  }
  F[i]  <- 5.35 * log(C_total[i] / 400) + ozone_forcing
  TK[i] <- (((solar * (1 - albedo[i]) / 4) + F[i] + L[i]) / (emiss * sigma))^0.25
  TC[i] <- TK[i] - 273.15
}

warming <- TC - TC[1]
mydata <- data.frame(year, C_anthro, C_total, F, TC, warming)
